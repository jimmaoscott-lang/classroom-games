# classroom-games

Review games for Brazoswood High School classes, each run as a Google Apps Script web app with Google Sheet reporting for teachers.

| Game | Folder | Status |
|---|---|---|
| Studio '68 (build-a-song rhythm review) | `games/studio-68` | Gameplay mockup done; full build next |
| Huddle Up (football coach review) | `games/huddle-up` | Build step 6 of 9 (Head-to-Head) done |
| The Exiled Crown (castle builder) | lives in `castlebuildermapsanditems` | Live; its Code.gs is the base for `shared/reporting` |

No student data is ever stored in this repo. Student results live only in each teacher's Google Sheet.
